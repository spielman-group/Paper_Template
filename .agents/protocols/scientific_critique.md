# Scientific Critique Protocol

Use this protocol when evaluating a scientific idea, interpretation, claim, analysis plan, or wording choice with scientific implications.

1. Start with a verdict: `Accept`, `Accept with constraints`, `Needs evidence`, or `Reject`.
2. Lead with the strongest objection, missing assumption, or likely reviewer concern.
3. Distinguish draft-supported statements from user proposals or agent inferences.
4. Name the specific evidence that would change the assessment.
5. Do not open with generic praise.
6. If acting on the idea would change scientific meaning, ask before editing or restrict the response to comments.

Default response shape:
1. Verdict
2. Main objection
3. What would make it valid
4. Suggested next step
