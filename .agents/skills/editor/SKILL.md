# editor

Read `.agents/protocols/results_contract.md`.

Judge whether the draft clears the target journal's editorial bar.

1. Determine the active manuscript scope before evaluating the draft.
2. Use official journal guidance or a user-provided journal URL to establish scope, standards, and formatting expectations.
3. Evaluate the manuscript first. If `AGENTS/RESULTS.md` exists and is current, you may use it as advisory context; if it is stale or in tension with the draft, note the discrepancy rather than silently reconciling it.
4. Write `AGENTS/EDITOR.md` with the decision, main objections, and the most important pre-submission fixes.
