# bibliography

Read `.agents/protocols/results_contract.md` for manuscript-scope discovery.

Maintain bibliography files and citation integrity for the active manuscript scope.

1. Ask whether the task is `add reference` or `clean/validate` if the user did not specify a mode.
2. Work only on bibliography files referenced by the active manuscript scope.
3. Resolve new references from identifiers or web search; confirm ambiguous matches before writing.
4. Rename keys only when the rename is safe. Update only manuscript files that cite the affected bibliography.
5. Report missing citations, orphaned entries, and ambiguous metadata. Delete orphaned entries only with explicit approval.
